# データ利用条件の整理、使用データの可否

---

## 1. 事務局アナウンスの整理

### 1.1 ルールの全体像

- **① 東京都オープンデータカタログサイト掲載データ**（catalog.data.metro.tokyo.lg.jp）
  - 許諾不要。そのまま使える
  - 個別ライセンス規定がある場合はそちらに準拠
- **② CCライセンス等が明記されているデータ**
  - 許諾不要。そのまま使える
- **③ 東京都保有だが ①② に該当しないデータ**（都の公式HP掲載データなど）
  - 開発開始時点から【ダミーデータ】で進める
  - 許諾申請は継続してよいが、下りる保証はない
- **④ 都庁以外の自治体（区市町村・他都道府県）のデータ**
  - 東京都の判断が及ばない。自分で利用規約を確認し、必要なら個別に許諾申請

### 1.2 ③なぜダミーデータなのか（背景）
- 東京都公式HPの「著作権・リンクについて」により、私的使用等を除き無断複製・転用は不可
- 開発中の非公開段階なら直ちに問題化しないが、**First Stage（8/26〜31収録）で一般公開された瞬間**に許諾なし利用が表面化
- → 最初からダミー、許諾が下りたらファイナル進出後に実データへ差し替え

## 2. ライセンスの実地確認結果

### 2.1 東京都オープンデータカタログサイト（利用規約）
確認先: https://portal.data.metro.tokyo.lg.jp/terms/

- 掲載コンテンツの著作権は、「注」があるものを除き **クリエイティブ・コモンズ・ライセンス 表示 4.0 国際（CC BY 4.0）** のもとでライセンス
- 複製・公衆送信・翻訳・変形等の翻案が自由（**商用利用も可能**）
- **クレジット表記が必要**（改変なしの場合と改変ありの場合で記載例が異なる）
- 別の利用ルールが個別適用されるコンテンツは、そちらが優先

### 2.2 クレジット表記のテンプレート

改変して利用する場合（本プロダクトは全て改変利用に該当）:

```
このデータは以下の著作物を改変して利用しています。
「【データセット名】」（東京都【所管局名】）
（https://catalog.data.metro.tokyo.lg.jp/dataset/【ID】）
東京都オープンデータ利用規約、クリエイティブ・コモンズ・ライセンス 表示4.0 国際
```

> 「クリエイティブ・コモンズ・ライセンス 表示4.0国際」の文字にハイパーリンクを貼る形でも可。
